Morning Market — Spot the Difference! A complete, original spot the difference game set in an Indonesian morning market. Six stalls — Fruit Stall (8 differences), Coffee Stall (8), Flower Stall (8), Fish Stall (9), Fabric Stall (8) and Toy Stall (9) — 50 differences in all. Each stall shows two near-identical pictures side by side. Click a difference (or move the crosshair with the arrow keys and press Enter) to mark it with a green ring on both panels; wrong clicks cost 5 seconds. A big counter shows how many differences remain, hints are limited to 3 per stall, the timer gets shorter as the stalls get harder, and a magnifier lens follows your mouse so tiny changes are easy to check. Score, streaks, level select, a win screen and restart are all included. All art is drawn in code with canvas primitives and all sounds are synthesised with WebAudio — no images, fonts or sounds are loaded from the network.

## Run it

```sh
cd game && python3 -m http.server 8080
```

Then open http://localhost:8080 in a desktop browser. Keyboard: arrow keys move the crosshair, Enter checks a spot, H hint, R restart level, N next level, 1-6 jump to a stall, M mute.
